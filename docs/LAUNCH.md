# چک‌لیست راه‌اندازی — از کد آماده تا ربات روشن

کد بک‌اند کامل است. این‌ها کارهایی است که **بیرون از کد** باید انجام شود تا ربات روی یک پیج واقعی کار کند، و بعد برای فروش عمومی.
ترتیب مهم است؛ هر مرحله پیش‌نیاز بعدی است. کنار هر کار نوشته شده چه چیزی از آن به دست می‌آید و کجا استفاده می‌شود.

جزئیات متا: [راهنمای متا](https://claude.ai/artifact/3HTsJMZapTFufMRFyH4NbB) · جزئیات فرانت: [FRONTEND.md](FRONTEND.md)

## مرحله ۱ — حساب‌ها و تصمیم‌ها (همین هفته، موازی)

- [ ] **اسم برند + دامنه** (ترجیحاً `.com`). دو زیردامنه لازم است: `api.` برای بک‌اند و `panel.` (یا خود دامنه) برای پنل.
- [ ] **ایمیل روی دامنه** (مثلاً `support@...`). برای Business Verification متا و ایمیل پشتیبانی در صفحه‌ی Privacy لازم است.
- [ ] **حساب سرویس هوش مصنوعی** (درگاه ایرانی سازگار با OpenAI): شارژ اولیه و گرفتن سه مقدار:
  - آدرس API → `LLM_BASE_URL`
  - کلید → `LLM_API_KEY`
  - اسم مدل → `LLM_MODEL` (یک مدل سریع که **tool/function calling** دارد؛ اگر مطمئن نیستی، کلید را بده تا با یک اسکریپت چند مدل را روی سوال‌های فارسی مقایسه کنم)
  - اختیاری: مدلی که عکس می‌خواند → `LLM_VISION_MODEL` (برای آپلود عکس لیست قیمت)
- [ ] **اکانت توسعه‌دهنده‌ی متا + Business Portfolio + ساخت اپ** (مرحله‌ی ۱ راهنمای متا). از صفحه‌ی *Instagram → API setup with Instagram login* بردار:
  - Instagram app ID → `META_APP_ID`
  - Instagram app secret → `META_APP_SECRET`
  - (نه App ID فیسبوکِ بالای داشبورد)
- [ ] **پیج تستی اینستاگرام** بساز و Professional کن (Business یا Creator).
- [ ] **تصمیم درباره‌ی شرکت خارجی** + مشاوره‌ی حقوقی. برای تست لازم نیست؛ برای فروش عمومی لازم است (مرحله ۵). زودتر شروع شود چون زمان‌بر است.

## مرحله ۲ — سرور (۱ روز)

- [ ] **VPS اروپا** (آلمان/هلند/فنلاند)، Ubuntu 24.04، حداقل ۲ هسته و ۴ گیگ رم (برای شروع کافی است؛ بعداً ۴ هسته / ۸ گیگ).
- [ ] **DNS:** رکورد `A` برای `api.دامنه` → IP سرور. (پنل هم بسته به جایی که علی دیپلوی می‌کند.)
- [ ] روی سرور: نصب Docker، فقط پورت‌های 22، 80، 443 باز، ورود SSH فقط با کلید.
- [ ] کد را در یک **ریپوی خصوصی** (GitHub/GitLab) بگذار و روی سرور clone کن.
- [ ] **فایل `.env`** را از `.env.example` بساز و پر کن:

  | مقدار | از کجا |
  |---|---|
  | `API_DOMAIN`, `PUBLIC_BASE_URL` | دامنه‌ی `api.` |
  | `FRONTEND_URL`, `CORS_ORIGINS` | آدرس پنل |
  | `POSTGRES_PASSWORD` | یک رمز تصادفی قوی |
  | `SECRET_KEY` | `python -c "import secrets; print(secrets.token_urlsafe(48))"` |
  | `ENCRYPTION_KEY` | `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"` |
  | `META_APP_ID`, `META_APP_SECRET` | مرحله ۱ |
  | `META_WEBHOOK_VERIFY_TOKEN` | یک رشته‌ی تصادفی دلخواه (همان را در متا هم وارد می‌کنی) |
  | `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` | مرحله ۱ |

  > ⚠️ از `ENCRYPTION_KEY` یک نسخه‌ی امن جای دیگر نگه دار (مثلاً password manager). اگر گم شود، توکن‌های اینستاگرام همه‌ی مشتری‌ها غیرقابل خواندن می‌شوند و همه باید دوباره وصل کنند.

- [ ] اجرا: `docker compose up -d --build` و بعد باز کردن `https://api.دامنه/health/ready` → باید `{"status":"ready"}` ببینی.
- [ ] **بکاپ روزانه‌ی دیتابیس** (`pg_dump`) به جایی بیرون از همان سرور.
- [ ] **مانیتورینگ ساده:** یک سرویس uptime (مثل UptimeRobot) روی `/health/ready`.

## مرحله ۳ — وصل کردن متا به سرور (۱ ساعت)

در App Dashboard، بخش *Instagram → API setup with Instagram login*:

- [ ] **OAuth Redirect URI:** `https://api.دامنه/api/v1/instagram/callback`
- [ ] **Webhooks:** Callback URL = `https://api.دامنه/webhooks/instagram`، Verify token = همان `META_WEBHOOK_VERIFY_TOKEN` → *Verify and save* (اگر سرور درست بالا باشد، سبز می‌شود) → فیلد **`messages`** را Subscribe کن.
- [ ] **App roles → Instagram testers:** پیج تستی را اضافه کن، بعد در خود اینستاگرام: Settings → Website permissions → Apps and websites → Tester invites → قبول.

## مرحله ۴ — اولین تست واقعی (بعد از آماده شدن پنل علی)

- [ ] پنل روی دامنه دیپلوی شده باشد.
- [ ] در پنل ثبت‌نام کن → اتصال اینستاگرام با پیج تستی.
- [ ] روی پیج تستی: Settings → Messages and calls → Connected tools → **Allow access to messages** روشن.
- [ ] اطلاعات فروشگاه + (اختیاری) لینک گوگل شیت محصولات.
- [ ] صفحه‌ی **تست ربات**: ۱۰–۲۰ سوال واقعی مشتری بپرس و جواب‌ها را بسنج. (در این مرحله با هم پرامپت و مدل را تنظیم می‌کنیم.)
- [ ] ربات را روشن کن و **از یک اکانت اینستاگرام دیگر** به پیج تستی دایرکت بده:
  - [ ] سوالی که جوابش در اطلاعات هست → جواب درست
  - [ ] سوال قیمت/موجودی → جواب از روی شیت
  - [ ] سوالی که جوابش نیست → «پیام جواب ندادن» + ظاهر شدن در «ارجاع‌شده به شما»
  - [ ] خودت از اینستاگرام جواب بده → ارجاع خودکار بسته شود و ربات ساکت شود
- [ ] نتیجه را برای من بفرست؛ هر جا با واقعیت متا فرق داشت، همان‌جا درستش می‌کنم (این اولین تماس کد با سرورهای واقعی متاست).

> تا اینجا ربات **واقعاً کار می‌کند**، ولی فقط برای پیج‌هایی که Instagram tester شده‌اند. چند فروشگاه بتا را می‌شود همین‌طوری تستر کرد.

## مرحله ۵ — فروش عمومی (چند هفته، بیشترش انتظار برای متا)

- [ ] صفحه‌های **Privacy / Terms / Data deletion** روی دامنه (کار علی) + آیکون اپ ۱۰۲۴×۱۰۲۴ در تنظیمات اپ متا.
- [ ] **نسخه‌ی انگلیسی پنل** (یا حداقل مسیر اصلی) برای داور متا.
- [ ] **Business Verification** با مدارک شرکت خارجی.
- [ ] **App Review** برای `instagram_business_basic` و `instagram_business_manage_messages`: ویدیوی کامل مسیر + یوزر و رمز تستی برای داور.
- [ ] بعد از تأیید: اپ روی **Live**.

## مرحله ۶ — کسب‌وکار (بعد از بتا؛ کد این بخش‌ها هنوز نوشته نشده)

- [ ] **درگاه پرداخت ایرانی + اینماد** → اشتراک ماهانه. (احتمالاً سایت فروش و پرداخت روی سرور ایران، ربات روی سرور اروپا.)
- [ ] **سرویس پیامک** (برای ورود با موبایل، فراموشی رمز، اعلان ارجاع به مدیر).
- [ ] **قیمت‌گذاری:** از `tokens_this_month` در داشبورد فروشگاه‌های بتا، هزینه‌ی واقعی هر فروشگاه را حساب کن.
